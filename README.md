# Loja Compre Bem

Projeto de exemplo desenvolvido durante as aulas para praticar conceitos de React Native e Expo.

## Funcionalidades

- Lista de produtos utilizando FlatList
- Navegação entre lista e detalhe
- Passagem de parâmetros entre telas
- Exibição do produto selecionado

## Tecnologias

- React Native
- Expo
- TypeScript
- React Navigation
