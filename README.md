# Loja Compre Bem — Expo SDK 57

Projeto de exemplo desenvolvido durante as aulas para praticar conceitos de React Native e Expo.

## Versões principais

- Expo SDK 57 (`expo ~57.0.22`)
- React Native 0.86.3
- React 19.2.3
- TypeScript
- React Navigation

## Como instalar e executar

É recomendado usar Node.js 22.13 ou superior.

Dentro da pasta do projeto:

```bash
npm install
npx expo-doctor@latest
npx expo start
```

Depois, abra o Expo Go SDK 57 no celular e leia o QR Code exibido pelo terminal.

## Funcionalidades

- Lista de produtos utilizando FlatList
- Navegação entre lista e detalhe
- Passagem de parâmetros entre telas
- Cadastro de produtos com validação
- Correção de responsividade da Aula 13

## Aula 13

Os campos `TextInput` do formulário receberam `minHeight: 44`, garantindo uma área mínima adequada para toque nas diferentes resoluções testadas.

O registro da atividade está em `exercicio.md`.
